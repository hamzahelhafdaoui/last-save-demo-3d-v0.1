# Quality-led next milestones

The investor demo and full game remain separate. Complete the demo's quality gates before beginning production-scale infrastructure.

## 1. Reliable owner-playable core

- Finish continuous end-to-end playthroughs on native desktop hardware, including the physical crossing, three puzzles, guardian, sword, city, jacket, home display and reload.
- Record failures with reproducible steps. Fix blocked approaches, unclear objectives and camera collisions before adding breadth.
- Validate the three modes independently. Story Tour should remain forgiving; Adventure needs fair telegraphs and readable retries; Living Quest needs reviewed combat/navigation and rewards.
- Add save import alongside export, safe checkpoint recovery, and explicit browser/device QA.

## 2. Character and Dawnwake presentation

- Review and author a final protagonist rather than treating the current original character as an approved final design.
- Create reviewed idle/walk/run/sprint/jump/landing, turns, facial reactions, grip, strain, extraction, overhead raise, examination, attack, hit and dodge animation.
- Refine contact, foot placement and camera framing throughout Dawnwake. Eliminate clipping and visible rig stretching.
- Author final sword, pedestal fracture meshes, sanctuary set pieces, lighting progression, atmospheric cloud separation, VFX and synchronized score/Foley.
- Compare captured footage against the intended experience; keep revising instead of equating functional animation with finished cinematic quality.

## 3. Cohesive, dense worlds

- Lumenreach: art-directed terrain and foliage, ancient trees, river/waterfall integration, painted materials, village silhouettes, interiors/props, animals and contextual NPC behavior.
- Home: composed lighting, high-quality furniture, believable exterior/interior transition, meaningful collectible placement and wardrobe presentation.
- City: stronger skyline/storefront composition, material variation, measured reflection strategy, improved jacket design and distinct resident identities.
- Keep areas compact and remove low-value visual clutter. Measure geometry, materials, draw calls and texture memory on target devices.

## 4. Audio, interaction and accessibility

- Replace musical sketches with reviewed original/licensed scores, layered ambience, dialogue reactions and cinematic audio.
- Improve interaction affordances, spatial guidance and objective timing through observed playtests.
- Validate volume/mute, reduced motion, keyboard focus, contrast, window resizing and gamepad support.
- Physical mobile testing follows the desktop quality pass; do not assume touch emulation proves device performance.

## 5. Investor presentation gate

A coherent 8–15 minute run must be timed on target hardware and reviewed by the owner. The game must reliably show one identity taking Dawnwake into Velvet City, wearing the new jacket, and returning home with lasting memories. Ship an updated walkthrough, verified production URL, reproducible source tag, QA evidence and a clear limitations list.

Only after this gate: propose full-game architecture for multiplayer, accounts, cloud identity/save, social worlds, creator tools, content publishing, licensing, moderation and scalable operations. These are future work, not features implemented in this demo.
