Editable production export of the **regular LAST SAVE game's current music**.

Download `LAST-SAVE-Soundtrack-Production.zip` and extract it before opening projects. Includes:

- 24 aligned 48 kHz / 24-bit stereo WAV stems, separated from the original synthesis code.
- Four reference mixes and unchanged in-game OGGs.
- Multitrack and individual-layer MIDI (28 files), with tempo and note data.
- Five native REAPER projects: one per cue plus the full 96-second arrangement.
- A listening MP3, sound recipe/source code, checksums and export verification.
- An actual screenshot of the open REAPER multitrack session.
- FL Studio import instructions. **No native FLP is supplied.**

Home, Lumenreach and sanctuary: **40 BPM, 4/4**. Velvet City: **120 BPM, 4/4**. Each cue is 24 seconds. Set the tempo, then place all six stems from a cue at bar 1 on separate tracks without time stretching; import MIDI to replace/edit instruments.

These are the existing four short procedural sketches, not newly composed long-form orchestral tracks. The source synthesis is 22.05 kHz, resampled for DAW compatibility. Runtime gameplay sound effects and crossfades are outside this music pack.

All five sessions were opened in REAPER with no missing assets. The full-session offline render matched the sum of exported stems exactly. MIDI timing, WAV format/alignment, no clipping, ZIP CRC and file checksums were validated. FL Studio itself was not available for a native import test.

Source and reproducible authoring tools: https://github.com/hamzahelhafdaoui/last-save-demo-3d-v0.1/tree/media/soundtrack-production/soundtrack
