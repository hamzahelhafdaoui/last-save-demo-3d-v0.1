# Soundtrack export branch

This is a media-only branch for exporting the regular game's existing music. The game runtime and Vercel main deployment must remain unchanged. Commit/push source, sessions, documentation and publishing workflow here; publish generated audio as permanent GitHub release assets. Never claim a native FL Studio project: the native session is REAPER, with WAV and MIDI for other DAWs. The source cues are four 24-second synthesized sketches, not a newly composed orchestral soundtrack.
